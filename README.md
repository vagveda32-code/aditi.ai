# SuktaVaani AI + अदिति — अथर्ववेद स्क्रिप्ट स्टूडियो और बोलने-सुनने वाली सहायिका

- `/` (index.html) — **SuktaVaani**: सूक्त चुनिए → वीडियो-स्क्रिप्ट (7 भाषाएँ), नीचे दाएँ **अदिति** बटन
- `/aditi.html` — सिर्फ़ अदिति, पूरे पेज पर

कोई भी व्यक्ति लिंक खोलकर कमल दबाए, बोले — अदिति सुनती है, अथर्ववेद सूक्त का अर्थ/महत्त्व बताती है और बोलकर जवाब देती है।

## फ़ाइलें
- `public/index.html` — SuktaVaani ऐप (अदिति अंदर जुड़ी हुई)
- `public/aditi.html` — अलग से सिर्फ़ अदिति
- `public/logo.svg` — अदिति का कमल-नक्षत्र लोगो
- `netlify/functions/aditi/aditi.mjs` — server function (Sarvam key यहीं छिपी रहती है)
- `netlify/functions/aditi/search.mjs` — ग्रंथ में सही सूक्त ढूँढने वाला हिस्सा
- `netlify/functions/aditi/data.mjs` — आपके PDF (डा. गंगा सहाय शर्मा, अथर्ववेद हिंदी) का पूरा पाठ: 20 काण्ड, 754 सूक्त, मंत्र + अर्थ
- `netlify.toml` — Netlify सेटिंग

## चरण 1 — Sarvam API key (आपके नाम से)
> आपकी key `netlify/functions/aditi/aditi.mjs` में पहले से जुड़ी है, इसलिए नीचे के Environment variable वाले चरण अब ज़रूरी नहीं हैं। यह zip या फ़ोल्डर किसी को न दें और public GitHub पर न डालें। GitHub इस्तेमाल करें तो repo **Private** रखें।

1. https://dashboard.sarvam.ai पर जाकर अपने email/फ़ोन से sign up करें।
2. Dashboard → **API Keys** → नई key बनाएँ और copy करें।
3. यह key किसी को न भेजें, chat में भी नहीं।

## चरण 2 — Netlify पर डालना
1. https://app.netlify.com पर अपने email से sign up करें (मुफ़्त)।
2. **Add new site → Deploy manually** चुनें और यह पूरा `aditi-voice` फ़ोल्डर (zip खोलकर) खींचकर डालें।
   - अगर functions न चलें तो GitHub पर फ़ोल्डर डालकर **Import from Git** से जोड़ें।
3. Site → **Site configuration → Environment variables → Add variable**
   - Key: `SARVAM_API_KEY`
   - Value: आपकी Sarvam key
4. **Deploys → Trigger deploy** दबाएँ।
5. मिला हुआ लिंक (जैसे `aditi-xyz.netlify.app`) फ़ोन के Chrome में खोलें → कमल दबाएँ → mic **Allow** करें → बोलें।

## इस्तेमाल
- कमल दबाइए → बोलिए → चुप होते ही अदिति समझकर जवाब बोलेगी।
- "लगातार बातचीत" चालू हो तो जवाब के बाद अदिति अपने आप फिर सुनेगी।
- बोलते समय कमल दबाने से आवाज़ रुक जाती है।
- लिखकर भी पूछ सकते हैं।

## स्क्रिप्ट (SuktaVaani)
- अब Claude की ज़रूरत नहीं — स्क्रिप्ट भी Sarvam से, इसी ग्रंथ के आधार पर बनती है और लिखते-लिखते दिखती है।
- ऊपर "आधार: अथर्ववेद 12.1" दिखता है कि कौन-सा सूक्त आधार बना।
- Netlify function की सीमा लगभग 30 सेकंड है; 5-10 मिनट की लंबी स्क्रिप्ट बीच में कट सकती है। ऐसा हो तो छोटी अवधि चुनें या दो हिस्सों में बनवाएँ।
- Save .txt अब सीधे फ़ोन में download होता है।

## ग्रंथ ही आधार
- हर सवाल पर अदिति पहले ग्रंथ में मिलता-जुलता सूक्त ढूँढती है (नाम, देवता, काण्ड-सूक्त संख्या जैसे "12.1" या "काण्ड 19 सूक्त 53", या मंत्र के शब्द), और उसी के मंत्र-अर्थ के आधार पर जवाब देती है। जवाब के नीचे "आधार: अथर्ववेद 12.1" दिखता है।
- कन्नड़/तेलुगु/English में पूछे सवाल को खोज के लिए पहले हिंदी में बदला जाता है (Sarvam translate)।
- काण्ड-सूक्त संख्या इसी ग्रंथ की क्रम-संख्या है। कुछ काण्डों में यह ग्रंथ पर्याय-सूक्तों को अलग गिनता है (जैसे इसमें प्राण सूक्त 11.6, ब्रह्मचारी सूक्त 11.7, काल सूक्त 19.53-54)।
- पाठ PDF से OCR द्वारा निकाला गया है, इसलिए कहीं-कहीं मंत्र में मात्रा/अक्षर की छोटी गलती हो सकती है।

## खर्च और सुरक्षा
- हर सवाल पर Sarvam के तीन काम होते हैं: सुनना (STT), जवाब (Chat), बोलना (TTS); हिंदी/मराठी के अलावा भाषाओं में एक छोटा translate भी। खर्च उसी हिसाब से आपके Sarvam खाते से कटेगा।
- लिंक सार्वजनिक है, इसलिए Sarvam dashboard में usage पर नज़र रखें और ज़रूरत हो तो limit लगाएँ।
